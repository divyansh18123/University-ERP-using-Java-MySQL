# University ERP System
A full-stack University ERP System built using Java and MySQL to streamline academic and administrative operations within a university.
This project provides a centralized platform to manage student, faculty, and course-related activities efficiently. It reduces manual processes and ensures data consistency across departments.

## Features
- Student registration and profile management  
- Course enrollment and timetable management  
- Faculty and department administration  
- Attendance tracking and academic record management  
- Secure login with role-based access control  

## Tech Stack
- Backend: Java  
- Database: MySQL  
- Technologies & Concepts: JDBC, OOP, SQL, Database Normalization  

## Objective
To design and implement a scalable ERP solution that enhances workflow automation and improves institutional data management.
